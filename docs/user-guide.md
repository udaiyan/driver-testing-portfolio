# User Guide — Mock AV Driver

## What you can do
- Turn the device on and off
- Change volume
- Check status

## Basic controls
| Button | Action |
|---|---|
| Power On | Turns the device on |
| Power Off | Turns the device off |
| Volume +/- | Adjusts volume |

## If something doesn't work
1. Check the device is powered.
2. Check the network.
3. Reboot the controller.
4. Contact support with the details from the installer guide.
