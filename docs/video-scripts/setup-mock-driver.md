# Video Script — Setup: Adding the Mock AV Driver

**Target duration:** 4 minutes
**Audience:** Installers

## 0:00 - Intro
"Hi, in this video I'll show you how to add and configure the mock AV driver in under five minutes."

## 0:20 - Prerequisites
- Driver file
- Device IP and port
- Composer Pro / Integration Designer open

## 0:45 - Add the driver
- Show adding the driver file.
- Highlight the driver appearing in the project.

## 1:30 - Configure
- Set IP `192.168.1.50`.
- Set port `5000`.
- Apply.

## 2:15 - Verify
- Status shows Online.
- Send Power On.
- Show device response.

## 2:50 - Common errors
- Offline: check IP.
- Auth error: check credentials.

## 3:30 - Wrap up
"Full details are in the installer guide. Thanks for watching."
