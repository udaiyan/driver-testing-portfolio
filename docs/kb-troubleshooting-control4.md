# KB: Control4 driver shows Offline

## Symptoms
- Driver status is Offline.
- Device does not respond.

## Quick checks
1. Confirm device IP.
2. Ping the device.
3. Confirm port.
4. Confirm driver is enabled.
5. Reboot Director.

## Advanced checks
- Check driver log for timeout errors.
- Confirm VLAN / firewall rules.
- Test with a second device.

## Escalation
Collect:
- Driver version
- Device model
- Logs
- Network diagram
