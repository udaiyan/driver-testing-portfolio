# Documentation Style Guide

## Voice
- Second person ("you"), active voice.
- Short sentences.

## Structure
- One idea per sentence.
- Numbered steps for procedures.
- One action per step.

## Formatting
- `code` for IPs, ports, file names.
- Tables for options.
- Screenshots labelled "Figure 1" etc.

## Accessibility
- Alt text on images.
- Don't rely on colour alone.

## Checklist
- [ ] Steps are numbered
- [ ] Commands are copy-pasteable
- [ ] No jargon without explanation
- [ ] Tested by following the guide yourself
