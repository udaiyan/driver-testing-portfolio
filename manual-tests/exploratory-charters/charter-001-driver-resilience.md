# Exploratory Charter 001 — Driver resilience under unstable network

**Time box:** 60 minutes
**Area:** Mock drivers (Control4, RTI, Crestron)
**Mission:** Find ways the driver can end up in a stuck or misleading state when the network is flaky.

## Heuristics to explore
- Intermittent reachability
- Rapid connect / disconnect cycles
- Keepalive timing edge cases
- Unknown commands
- Volume out-of-range values
